# S04 — UI critique

## Fixture
A settings flow has a blank screen while loading, no empty or server-error message, and keyboard focus disappears after dialog close. Mobile width causes the primary action to overflow.

## Task
Audit the user goal and full flow, map all relevant states, recommend bounded fixes consistent with the existing design system, and assess WCAG 2.2 AA.

## Required evidence
- Primary user task and hierarchy.
- Empty/loading/success/validation/system-error/disabled states.
- Keyboard order, visible focus, semantics, labels, contrast and target sizes.
- Responsive/reflow evidence at representative viewports.
